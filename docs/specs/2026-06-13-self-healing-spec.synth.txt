§3 DIAGNOSE-LAYER  [read-only ⇒ always✓; ≈80% of cognitive work]
  WC(classifier, exactly-one):
    a_skill_prompt   : model-misuse/desc-mismatch  ex:probe -h, ignore argv     → ℓ=SK(text)
    b_skill_script   : python wrong                 ex:gather_audits scan        → ℓ=SK(script·code-iso)
    c_workflow_config: provider/topo/force/merge    ex:parallel-flaky→sequential → ℓ=WF
    d_foundation_code: runtime/plumbing              ex:include_usage,$nodeSuccess,thoughtSig → ℓ=FN(PR⚠)
    e_transient_ext  : outage/ratelimit              ex:Gemini503,OpenAI429       → ℓ=∅(retry/backoff)
  TRAP: classify(e as a|c) ⇒ κ-waste ∧ unfixable. classifier ⊨ loop-honesty.
  OUTCOME_Q  (success≠good; "apology"=success✓∧bad):
    free-signals := {skill_exit_code, loop_detected, round_limit_hit, output_files?, user_action}
    LLM-judge := ONLY iff success ∧ suspicious(free-signal)   // minority
  LOCALIZE⊢/cluster: ⟨WC, provider, IM, locus, failure_patterns[], candidate_eval_cases[]⟩
    locus: FN→file/fn/line+hypo ; SK→{description|body} ; WF→{node,knob}
    failure_patterns[] ≡ improve_body input-contract (reuse).
    candidate_eval_cases := failing-run→regression-test (flywheel, §5.1).
  ROUTER:
    R1 IM=auto_discovery                      ⇒ SkillOpt.run_loop      (Δdescription)
    R2 IM∈{forced,workflow_node} ∧ WC=a       ⇒ SkillOpt.run_body_loop (Δbody)
    R3 WC=c                                    ⇒ WF-healer §5.2
    R4 WC=d                                    ⇒ FN-diagnostician → PR⚠ §5.3
    R5 WC=e                                    ⇒ retry/backoff ; ⊘fix
    R6 ∀: pick(cheapest-safe ℓ that hits root). general→SK(DRY); pipeline-local→WF; plumbing→PR.
    R7 mask-guard: WF-config-mitigation(c-shaped) ∧ root=d ⇒ STILL ⊢ FN-PR. (⊘paper-over-rot)

§3.5 APPROVAL-GATE  [diagnose=free·auto ; heal=κ ⇒ opt-in/heal]
  flow: diagnose(auto,free) → estimate → overlay⚠ → [approve] → heal

  overlay⊢{ problem:1-line+WC+provider ; plan:{loop,scope:1|N-prov,eval-model} ; est:~tok+~$(range) ;
            actions:{ Approve | Decline | Approve-cheaper:↓R,↓I,cheap-eval ⇒ ↓est-live } }
