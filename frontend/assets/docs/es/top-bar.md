# Botones de la barra superior

La barra superior agrupa los controles globales. Cada botón se describe a continuación.

| Botón | Función |
|-------|---------|
| Herramientas | Muestra/oculta la barra lateral izquierda (la caja de herramientas con Conversaciones, Verificar, Comparar, etc.). |
| Voz | Muestra/oculta el panel del asistente de voz. |
| Ayuda | Repite la visita guiada de introducción. |
| Documentación | Abre esta guía. |
| Configuración | Gestiona claves API, modelos por defecto, servidores MCP, proveedores de almacenamiento. |
| Cerrar sesión | Sale de tu sesión. |

## Herramientas

Muestra/oculta la barra lateral izquierda. Ocúltala para ganar espacio horizontal en la conversación; vuelve a mostrarla cuando necesites cambiar de herramienta.

## Voz

Abre el panel del asistente de voz. (La integración de voz está evolucionando — vuelve a consultar esta sección a medida que la función se estabilice.)

## Ayuda

Repite la visita guiada de introducción. Útil para refrescar lo básico o para guiar a un compañero por la aplicación.

## Documentación

Abre esta guía. La barra lateral lista cada servicio; el panel derecho muestra el artículo seleccionado.

## Configuración

El panel de configuración cubre claves API, modelos, servidores MCP, almacenamiento, preferencias de cuenta y más. Consulta la sección **Configuración** de esta guía.

## Cerrar sesión

Te desconecta y te devuelve a la página de inicio de sesión.
