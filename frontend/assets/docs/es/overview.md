# Visión general

Bienvenido a **GPT** — un espacio de trabajo para usar muchos proveedores de IA, y un arnés para diseñar workflows de agentes y compilarlos en código que se ejecuta en cualquier parte.

Esta documentación recorre todos los servicios que ofrece la aplicación. Usa la barra lateral para saltar entre secciones.

## Qué puedes hacer

- Conversar con **Claude, OpenAI, Gemini, Grok, DeepSeek, Kimi, GLM** y modelos autoalojados, en una misma conversación.
- **Verificar** la respuesta de un proveedor con otro, o **comparar** el mismo prompt entre proveedores.
- Adjuntar archivos Word, PowerPoint, Excel y PDF: se convierten en tu navegador para que cualquier modelo pueda leerlos.
- Usar **habilidades**: carpetas de instrucciones y scripts Python que se ejecutan en tu navegador sobre tu carpeta local.
- Conectar **servidores MCP** (Outlook, ServiceNow, SharePoint, búsqueda, bases de datos…) y usar sus herramientas en el chat y en los workflows.
- Diseñar **workflows** de agentes, dispatchers, playbooks y nodos de código; probarlos paso a paso; iniciarlos con un prompt, un horario o un evento.
- **Compilar** un workflow a Python autónomo para **LangGraph, Google ADK, Microsoft Agent Framework o NVIDIA OO Agents**.
- Guardar **prompts**, **agentes**, **playbooks** y **componentes de código** en bibliotecas, y explorar tu carpeta local (**almacenamiento de archivos**).

## Cómo funciona

La aplicación se ejecuta en tu navegador y puede instalarse como Progressive Web App (PWA). Usa una carpeta de tu ordenador para las habilidades, las salidas de los workflows y el runner Python local que ejecuta los workflows compilados.
