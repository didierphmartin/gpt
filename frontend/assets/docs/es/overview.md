# Visión general

Bienvenido a **Asistente IA** — tu espacio de trabajo colaborativo para interactuar con varios proveedores de IA.

Esta documentación recorre todos los servicios que ofrece la aplicación. Usa la barra lateral para navegar entre las secciones.

## Lo que puedes hacer

- Chatear con **6 proveedores de IA**: OpenAI, Claude, Grok, Gemini, DeepSeek y Kimi.
- **Verificar** la respuesta de un proveedor con otro.
- **Comparar** el mismo prompt entre dos proveedores en paralelo.
- Guardar y organizar **prompts** y **habilidades** reutilizables.
- Construir **workflows** automatizados que orquestan agentes de IA.
- Explorar una carpeta de **almacenamiento de archivos** local en tu equipo.

## Cómo se ejecuta

La aplicación se ejecuta como PWA (Progressive Web App), por lo que puede instalarse localmente y acceder de forma persistente a una carpeta de tu equipo para las salidas de los workflows.
