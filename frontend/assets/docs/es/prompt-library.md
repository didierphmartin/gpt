# Biblioteca de prompts

Guarda tus prompts para reutilizarlos con un solo clic más tarde.

## Organizar

- Crea carpetas para agrupar prompts relacionados.
- Arrastra y suelta para reordenar.
- Clic derecho para renombrar o eliminar.

## Guardar un prompt

Haz clic en el icono 💾 junto a cualquiera de tus mensajes — el prompt se añade a la biblioteca y puedes elegir una carpeta.

## Reutilizar un prompt

Haz clic en cualquier prompt guardado → aparece en el campo de entrada, listo para enviar o editar antes de enviar.

## Consejos

- Mantén los prompts cortos y parametrizables — deja marcadores como `{{tema}}` para la parte que personalizas cada vez.
- Agrupa los prompts por caso de uso (investigación, redacción, revisión de código…) en lugar de por proveedor — la mayoría de los prompts funciona con cualquier proveedor.
