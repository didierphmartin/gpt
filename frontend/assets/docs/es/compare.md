# Comparar respuestas

Envía el **mismo prompt a dos proveedores en paralelo** y visualiza las respuestas en paralelo.

![Captura de pantalla de Comparar respuestas](assets/docs/images/compare.png)

## Cuándo usarlo

- Elegir la mejor redacción para una audiencia.
- Detectar discrepancias entre modelos.
- Evaluar qué proveedor maneja mejor un tipo de tarea.
- Hacer pruebas A/B de prompts antes de añadirlos a tu biblioteca.

## Cómo funciona

Ambos proveedores reciben el mismo prompt al mismo tiempo. Sus respuestas se transmiten en streaming en dos columnas para que puedas leerlas mientras se generan. Los tokens se contabilizan por separado para cada lado.
