# Tips & shortcuts

A grab-bag of small things that make the app faster to use.

## Keyboard

- **Enter** — send your message.
- **Shift + Enter** — insert a new line in the prompt.
- **Esc** — close the tour, this documentation, or any open modal.

## Drag and drop

- Drop files onto the chat area to attach them — same as clicking the 📎 paperclip.
- Drop a skill onto the prompt input to attach it to your next message.

## Replay the tour

Click **Help** in the top bar at any time to replay the onboarding tour from step 1. The tour and this documentation cover slightly different angles — the tour points at UI elements, the documentation goes into depth.

## Switch language

The language selector in the top bar updates the entire UI, the onboarding tour, and this documentation in real time.

## Conversations vs. workflows

- Reach for a **conversation** when you're exploring or in a back-and-forth with the AI.
- Reach for a **workflow** when you have a repeatable multi-step process — especially one you'll want to schedule or compile to Python later.
