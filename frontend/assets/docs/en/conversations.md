# Conversations

The default mode. Type a message in the prompt area and the active AI provider answers in real time.

## Providers

Switch between 6 AI providers using the tabs above the chat: **OpenAI, Claude, Grok, Gemini, DeepSeek, Kimi**.

## Merge responses

The top-right checkbox controls what happens when you switch providers mid-conversation:

- **Checked** — the conversation is preserved when you switch provider, so you can ask another model to continue, refine, or critique the previous answer.
- **Unchecked** — switching providers clears the chat for a fresh start.

## Attachments

Click the 📎 paperclip or **drag files onto the chat** to attach:

- **PDF, Word, Excel, PowerPoint, HTML**
- Images (PNG, JPEG, WebP, GIF)
- Plain text, Markdown, CSV, JSON

The AI reads and analyzes them as part of the prompt.

## SVG charts

Ask for a chart, diagram, or table — the AI returns SVG code that renders inline in the response.

## Conversation history

Every conversation is auto-saved and listed in the sidebar. Click an entry to reopen it; right-click for rename or delete.

## Per-prompt action icons

The blue ribbon next to each prompt has these actions:

- ☁️ Save the response to Google Drive.
- 🖨️ Print the response.
- 💾 Save the prompt to your Prompt Library.
- 📋 Copy the response to clipboard.
- ❌ Delete this prompt + response pair from the conversation.
