# Top bar buttons

The top bar holds the global controls. Each button is described below.

| Button | Purpose |
|--------|---------|
| Tools | Show / hide the left sidebar (the toolbox with Conversations, Verify, Compare, etc.). |
| Voice | Toggle the voice assistant panel. |
| Help | Replay the onboarding tour. |
| Documentation | Open this guide. |
| Settings | Manage API keys, default models, MCP servers, storage providers. |
| Logout | Sign out of your session. |

## Tools

Toggles the left sidebar. Hide it to give the conversation more horizontal space; show it again whenever you need to switch tools.

## Voice

Opens the voice assistant panel. (Voice integration is evolving — check back as the feature stabilizes.)

## Help

Replays the guided onboarding tour. Use it to refresh on the basics or to walk a colleague through the app.

## Documentation

Opens this guide. The sidebar lists every service; the right pane shows the selected article.

## Settings

The settings panel covers API keys, models, MCP servers, storage, account preferences, and more. See the **Settings** section in this guide.

## Logout

Signs out and returns you to the login page.
