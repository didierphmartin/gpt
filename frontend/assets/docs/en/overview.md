# Overview

Welcome to **GPT** — a workspace for working with many AI providers, and a harness for designing agent workflows and compiling them into code you can run anywhere.

This documentation gives a tour of every service offered by the application. Use the sidebar to jump between sections.

## What you can do

- Chat with **Claude, OpenAI, Gemini, Grok, DeepSeek, Kimi, GLM** and self-hosted models, in one conversation.
- **Verify** an answer from one provider with another, or **compare** the same prompt across providers.
- Attach Word, PowerPoint, Excel and PDF files: they are converted in your browser so any model can read them.
- Use **skills**: folders of instructions and Python scripts that run in your browser against your local folder.
- Connect **MCP servers** (Outlook, ServiceNow, SharePoint, search, databases…) and use their tools in chat and workflows.
- Design **workflows** of agents, dispatchers, playbooks and code nodes; test them step by step; start them from a prompt, a schedule or an event.
- **Compile** a workflow into standalone Python for **LangGraph, Google ADK, Microsoft Agent Framework or NVIDIA OO Agents**.
- Save **prompts**, **agents**, **playbooks** and **code components** in libraries, and browse your local **file storage** folder.

## How it runs

The app runs in your browser and can be installed as a Progressive Web App (PWA). It works with a folder on your computer for skills, workflow outputs and the local Python runner that executes compiled workflows.
