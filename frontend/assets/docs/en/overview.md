# Overview

Welcome to **AI Assistant** — your collaborative workspace for working with multiple AI providers.

This documentation gives a tour of every service offered by the application. Use the sidebar to jump between sections.

## What you can do

- Chat with **6 AI providers**: OpenAI, Claude, Grok, Gemini, DeepSeek, and Kimi.
- **Verify** an answer from one provider with another.
- **Compare** the same prompt across two providers side-by-side.
- Save and organize **prompts** and **skills** for reuse.
- Build automated **workflows** that orchestrate AI agents.
- Browse a local **file storage** folder on your computer.

## How it runs

The app runs as a Progressive Web App (PWA), so it can be installed locally and persistently access a folder on your computer for workflow outputs.
