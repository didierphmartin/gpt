# Prompt Library

Save reusable prompts for one-click reuse later.

## Organize

- Create folders to group related prompts.
- Drag and drop to reorder.
- Right-click for rename or delete.

## Save a prompt

Click the 💾 icon next to any of your messages — the prompt is added to the library and you can pick a folder for it.

## Reuse a prompt

Click any stored prompt → it drops into the input, ready to send or tweak before sending.

## Tips

- Keep prompts short and parameterized — leave placeholders like `{{topic}}` for the part you customize each time.
- Group prompts by use case (research, writing, code review…) rather than by provider — most prompts work across providers.
