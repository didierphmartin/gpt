# Compare Response

Send the **same prompt to two AI providers in parallel** and view the answers side-by-side.

![Compare Response screenshot](assets/docs/images/compare.png)

## When to use it

- Pick the best wording for a given audience.
- Spot disagreements between models.
- Evaluate which provider best handles a particular task type.
- A/B test prompts before adding them to your library.

## How it works

Both providers receive the same prompt at the same time. Their responses stream into two columns so you can read them as they're generated. Tokens are counted separately for each side.
