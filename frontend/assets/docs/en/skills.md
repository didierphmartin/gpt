# Skills

Skills are **reusable scenarios** that give the conversation specialized knowledge or behavior on the fly.

## Examples

- "Concise summarizer" — turns long content into bullet-point summaries.
- "SQL expert" — writes and reviews SQL with knowledge of common dialects.
- "Legal review assistant" — reviews contracts for risk clauses.
- "Code reviewer" — gives structured feedback on diffs.

## Using a skill

Drag a skill onto the prompt input — a chip appears showing the active skill. Your next message is sent with the skill's content prepended to the system prompt. Detach by clicking the chip's × button.

## Creating skills

- **From scratch** — write the skill content (system prompt) and save it.
- **From an existing agent** — extract an agent's instructions into a reusable skill so it can be attached to any conversation.

Skills can be tagged, categorized, and shared across the workspace (depending on your role package).
