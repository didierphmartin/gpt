# Conversations

Le mode par défaut. Tapez un message dans la zone de saisie et le fournisseur d'IA actif répond en temps réel.

## Fournisseurs

Basculez entre les 6 fournisseurs d'IA via les onglets au-dessus du chat : **OpenAI, Claude, Grok, Gemini, DeepSeek, Kimi**.

## Fusionner les réponses

La case en haut à droite contrôle ce qui se passe quand vous changez de fournisseur en cours de conversation :

- **Cochée** — la conversation est conservée quand vous changez de fournisseur, ce qui permet de demander à un autre modèle de continuer, d'affiner ou de critiquer la réponse précédente.
- **Décochée** — changer de fournisseur efface la conversation pour repartir de zéro.

## Pièces jointes

Cliquez sur le 📎 trombone ou **glissez des fichiers sur le chat** pour joindre :

- **PDF, Word, Excel, PowerPoint, HTML**
- Images (PNG, JPEG, WebP, GIF)
- Texte brut, Markdown, CSV, JSON

L'IA les lit et les analyse dans le cadre du prompt.

## Graphiques SVG

Demandez un graphique, un schéma ou un tableau — l'IA renvoie du SVG qui s'affiche directement dans la réponse.

## Historique des conversations

Chaque conversation est sauvegardée automatiquement et listée dans la barre latérale. Cliquez sur une entrée pour la rouvrir, clic droit pour renommer ou supprimer.

## Icônes d'action par prompt

Le ruban bleu à côté de chaque prompt offre ces actions :

- ☁️ Sauvegarder la réponse sur Google Drive.
- 🖨️ Imprimer la réponse.
- 💾 Sauvegarder le prompt dans la bibliothèque.
- 📋 Copier la réponse dans le presse-papiers.
- ❌ Supprimer cette paire prompt + réponse de la conversation.
