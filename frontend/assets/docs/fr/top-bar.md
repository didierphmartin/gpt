# Boutons de la barre supérieure

La barre supérieure regroupe les commandes globales. Chaque bouton est décrit ci-dessous.

| Bouton | Rôle |
|--------|------|
| Outils | Affiche/masque la barre latérale gauche (la boîte à outils avec Conversations, Vérifier, Comparer, etc.). |
| Voix | Affiche/masque le panneau de l'assistant vocal. |
| Aide | Rejoue la visite guidée d'introduction. |
| Documentation | Ouvre ce guide. |
| Paramètres | Gère les clés API, les modèles par défaut, les serveurs MCP, les fournisseurs de stockage. |
| Déconnexion | Quitte votre session. |

## Outils

Affiche/masque la barre latérale gauche. Masquez-la pour gagner de la place horizontale dans la conversation ; réaffichez-la quand vous voulez changer d'outil.

## Voix

Ouvre le panneau d'assistant vocal. (L'intégration vocale évolue — revenez consulter cette section au fur et à mesure que la fonctionnalité se stabilise.)

## Aide

Rejoue la visite guidée d'introduction. Utile pour réviser les bases ou pour faire visiter l'application à un collègue.

## Documentation

Ouvre ce guide. La barre latérale liste tous les services ; le volet droit affiche l'article sélectionné.

## Paramètres

Le panneau de paramètres couvre les clés API, les modèles, les serveurs MCP, le stockage, les préférences de compte, et plus encore. Voir la section **Paramètres** de ce guide.

## Déconnexion

Vous déconnecte et vous renvoie à la page de connexion.
