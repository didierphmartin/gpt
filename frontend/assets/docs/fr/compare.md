# Comparer les réponses

Envoyez le **même prompt à deux fournisseurs en parallèle** et visualisez les réponses côte à côte.

![Capture d'écran de Comparer les réponses](assets/docs/images/compare.png)

## Quand l'utiliser

- Choisir la meilleure formulation pour un public donné.
- Repérer les divergences entre les modèles.
- Évaluer quel fournisseur convient le mieux à un type de tâche.
- Tester des prompts avant de les ajouter à votre bibliothèque.

## Comment ça marche

Les deux fournisseurs reçoivent le même prompt en même temps. Leurs réponses sont diffusées en streaming dans deux colonnes pour pouvoir les lire à mesure qu'elles se génèrent. Les jetons sont comptés séparément pour chaque côté.
