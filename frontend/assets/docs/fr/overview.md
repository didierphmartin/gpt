# Vue d'ensemble

Bienvenue sur **GPT** — un espace de travail pour utiliser de nombreux fournisseurs d'IA, et un harnais pour concevoir des workflows d'agents et les compiler en code exécutable partout.

Cette documentation présente l'ensemble des services offerts par l'application. Utilisez la barre latérale pour naviguer entre les sections.

## Ce que vous pouvez faire

- Discuter avec **Claude, OpenAI, Gemini, Grok, DeepSeek, Kimi, GLM** et des modèles auto-hébergés, dans une même conversation.
- **Vérifier** la réponse d'un fournisseur avec un autre, ou **comparer** la même question entre fournisseurs.
- Joindre des fichiers Word, PowerPoint, Excel et PDF : ils sont convertis dans votre navigateur pour que tout modèle puisse les lire.
- Utiliser des **compétences** : des dossiers d'instructions et de scripts Python qui s'exécutent dans votre navigateur sur votre dossier local.
- Connecter des **serveurs MCP** (Outlook, ServiceNow, SharePoint, recherche, bases de données…) et utiliser leurs outils dans le chat et les workflows.
- Concevoir des **workflows** d'agents, de dispatchers, de playbooks et de nœuds de code ; les tester pas à pas ; les démarrer par une question, un horaire ou un événement.
- **Compiler** un workflow en Python autonome pour **LangGraph, Google ADK, Microsoft Agent Framework ou NVIDIA OO Agents**.
- Enregistrer **prompts**, **agents**, **playbooks** et **composants de code** dans des bibliothèques, et parcourir votre dossier local (**stockage de fichiers**).

## Fonctionnement

L'application s'exécute dans votre navigateur et peut être installée comme Progressive Web App (PWA). Elle utilise un dossier sur votre ordinateur pour les compétences, les sorties des workflows et le runner Python local qui exécute les workflows compilés.
