# Bibliothèque de prompts

Sauvegardez vos prompts pour les réutiliser en un clic plus tard.

## Organiser

- Créez des dossiers pour regrouper les prompts apparentés.
- Glissez-déposez pour réorganiser.
- Clic droit pour renommer ou supprimer.

## Sauvegarder un prompt

Cliquez sur l'icône 💾 à côté de l'un de vos messages — le prompt est ajouté à la bibliothèque et vous pouvez choisir un dossier.

## Réutiliser un prompt

Cliquez sur n'importe quel prompt enregistré → il s'insère dans la zone de saisie, prêt à être envoyé ou modifié avant l'envoi.

## Astuces

- Gardez les prompts courts et paramétrables — laissez des variables comme `{{sujet}}` pour la partie que vous personnalisez à chaque fois.
- Regroupez les prompts par cas d'usage (recherche, rédaction, revue de code…) plutôt que par fournisseur — la plupart des prompts fonctionnent avec tous les fournisseurs.
